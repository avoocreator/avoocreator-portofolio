# design-source

Berkas sumber (tidak ikut disajikan ke pengunjung).

`mascot/*.svg` adalah maskot orisinal (±1 MB per berkas karena berisi gambar raster di dalamnya).
Versi yang dipakai situs ada di `public/assets/mascot/*.webp` (±65 KB, tampilan sama).

Kalau mengganti maskot: ekspor ke WebP 1000×1000 dengan latar transparan lalu timpa berkas di
`public/assets/mascot/` dengan nama yang sama.
